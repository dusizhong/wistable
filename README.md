# WisTable智能表格系统

本项目是基于APITable开源版二开的多维表格系统。为了方便学习和内部使用，在原版基础上清理了大量非核心代码，修改了大量原功能。由于水平有限，本项目存在大量的bug和未知问题，请不要用于生产环境！
APITable是成熟的多维表格系统，拥有多年运行经验和众多用户，如需一个生产级、稳定可靠的多维表格系统，请使用APITable！

## 功能简介

- 强大的多维表格，支持多种字段类型
- 多人协作，支持分享给多人在线编辑
